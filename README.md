# EngHub_Win

Windows 데스크톱용 영어 학습 통합 애플리케이션 (Android 버전 [EngHub](https://github.com/hdlee73/EngHub)의 Windows 공식 포팅 버전)입니다.

---

## 🌟 주요 기능 및 핵심 개선 사항

### 1. 리스닝 백그라운드 연속 재생 (개선 반영)
- 리스닝 화면에서 재생 중 다른 메뉴(단어장, 리딩, 퀴즈, 번역 등)로 넘어가더라도 **재생이 정지되지 않고 계속적으로 연속 재생**됩니다.
- 앱 하단에 상시 표시되는 **미니 플레이어 바(Mini Player Bar)**를 통해 어느 화면에서나 트랙 정보 확인, 탐색 및 재생/일시정지 제어가 가능합니다.

### 2. SRT 자막 생성 시 단일 문장 타임랩 일원화 (개선 반영)
- 대본 및 오디오에서 `.srt` 자막을 생성할 때, 하나의 온전한 문장임에도 글자 수 청크 분할에 의해 타임이 쪼개지고 끊기던 현상을 해결하였습니다.
- 동일한 문장은 온전한 시간 구간(`start --> end`)을 유지하며, 동일 문장 내 타임랩 분할 없이 자막이 매끄럽게 연결됩니다.

### 3. 자막 단어 선택 후 단어장 이동 및 복귀 시 해당 위치 이어듣기 (개선 반영)
- 리스닝 자막을 보다가 모르는 단어를 클릭하여 단어장·사전으로 이동했을 때, 해당 단어의 타임스탬프(`cue.startMs`)를 기억합니다.
- 단어장 상단에 제공되는 **`[🎧 트랙명 (MM:SS) 재생 복귀]`** 버튼을 누르거나 리스닝으로 복귀할 때, 해당 단어가 발음되는 시간 위치로 즉시 점프(`seekTo`)하여 이어듣기가 가능합니다.

### 4. 통합 영어 학습 기능
- **단어·사전 (Dictionary)**: 엄선된 숙어/표현 및 구글 온라인 사전/번역 연동, 내 단어장 저장/관리
- **리딩 (Reading)**: 엄선된 아티클 텍스트 리더 및 주제별 독해
- **단어카드 (Flashcards)**: 라이트너 박스 방식의 플래시카드 암기 세션
- **퀴즈 (Quiz)**: 단어장에 저장된 단어 기반 4지선다형 어휘 퀴즈
- **회화표현 (Phrases)**: 미국/영국 패턴, 관용구, 슬랭 검색
- **번역 (Translate)**: 실시간 텍스트 번역
- **자막 생성 (DocVoice)**: 정밀 문장 분할 및 SRT 자막 생성/저장 도구

## 🚀 실행 및 빌드 방법

### 요구 사항
- Windows 10 / 11 (x64)
- JDK 21+ (로컬 개발 및 빌드 시)

### 로컬 실행
```bash
./gradlew.bat run
```

### 테스트 실행 (하네스 테스트)
```bash
./gradlew.bat test
```

### 배포용 패키지 빌드
```bash
# Windows 무설치 단독 실행 폴더 생성 (런타임 포함)
./gradlew.bat createDistributable

# 단일 실행형 UberJar 생성
./gradlew.bat packageUberJarForCurrentOS
```
빌드된 실행 파일은 `build/compose/binaries/main/app/EngHub/EngHub.exe`에서 확인하실 수 있습니다.
